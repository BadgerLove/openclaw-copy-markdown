Copy as Markdown for OpenClaw

Unofficial. Not affiliated with the OpenClaw project.

Where it runs

The extension only runs on sites you switch it on for. To switch it on:

  1. Open your OpenClaw page.
  2. Click the puzzle-piece icon at the top right of the browser, then Copy as Markdown for OpenClaw.
  3. Click Enable on this site and allow the browser's prompt.

    How to use it

    Select text in a message. A Copy as Markdown button appears under the selection; click it and paste. You can also right-click the selection, or press the keyboard shortcut (set at chrome://extensions/shortcuts).

    Options

    Markdown flavour h4+ headings become bold, no horizontal rules, tables converted (below).
    Tables
    Right-click Shift + right-click still gives OpenClaw's own menu.
    Extras Applies to text selected in the page, not to text boxes.
