# Privacy

Copy as Markdown for OpenClaw collects nothing and sends nothing anywhere.

- It has no access to any website until you enable it for that site, and it
  only ever runs on the sites you enabled.
- On those sites it reads the text you select, when you ask it to copy, and
  writes the Markdown version to your clipboard. That happens entirely inside
  your browser.
- It makes no network requests. There are no analytics, no accounts and no
  remote code.
- Your settings (Markdown flavour and similar) are stored with the browser's
  extension storage; if you use browser sync, the browser syncs them like any
  other extension setting. The list of enabled sites is held by the browser as
  extension permissions and can be removed at any time from the options page.

Questions or problems: open an issue on the project's GitHub page.
